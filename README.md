# 拾忆 · 原版酒馆版

独立的 SillyTavern 扩展，基于拾忆 TT 0.21.93 的核心，当前版本 0.1.2。安装和更新地址独立，TT 版继续使用原项目。

## 安装

支持原版 **SillyTavern 1.17.x–1.19.x**，无需为拾忆升级酒馆。扩展管理 → 安装扩展，粘贴：

`https://github.com/cszgezi-lab/Shiyi-Memory-ST`

打开拾忆 → 设置，填写主总结连接的 API 地址、Key 和模型，即可开始使用。保留现有记忆、人物、总结、召回、日志、设置六页及手机布局。不要同时启用两个拾忆版本。

## 存档与备份

记忆、人物档案、批次、复盘和拾忆设置保存在当前站点、当前浏览器的独立 IndexedDB 中；按酒馆账户与聊天隔离。原始聊天、角色卡和世界书保持原样。

设置 → 本机存档，可导出与导入该账户的完整浏览器存档，**不包含 API Key**。更换设备、浏览器、站点地址或清除站点数据之前先导出。恢复时替换该账户的拾忆存档和设置，并先下载恢复前备份；需要相同酒馆账户以及原聊天身份，无法自动合并复制或重新导入后的不同聊天。当前聊天的小备份与本机完整存档是不同格式。

酒馆内的原生聊天更名会在来源身份核验通过后保留拾忆记忆。旧版没有原生更名通知时，人物聊天与当前群聊使用成功更名回执核验；**非当前群聊请先打开，再更名**。旧版更名请求不包含群聊归属，拾忆不会猜测并合并其它群聊的存档。

Key 单独保存在本机，不读取或修改酒馆主聊天的 Key。原版数据女仆的无用文件清理不涉及拾忆 IndexedDB。

## 已保留功能

手动/自动总结、单批重试/删除/恢复、暂停与继续计划、动态人设、时间与知情参考、词典、标签设置、召回与手动复盘沿用 TT 0.21.93。覆盖终点按选择执行，失败保留正式结果；截断后的聊天暂停自动接续，永不自动补回撤下的尾段。

动态人设读取当前绑定的世界书和角色卡，只在本次请求中替换可核查的人物来源。原版版不创建世界书镜像，人物档案以拾忆人物页和备份为准。

## 支持范围

- 实际记忆注入与动态人设来源替换要求酒馆主聊天使用 **Chat Completion**。文本生成接口仍可整理、管理和预览记忆，发送时保留原设定，不执行人设来源替换。
- 总结、人设、复盘和模型列表走原版认证转发，使用拾忆自己的连接与 Key。
- 向量、重排和非标准接口路径使用浏览器直连，服务需要允许 CORS；失败时保留基础本地召回。
- 原版转发不完整保留上游 Retry-After/部分错误状态；拾忆沿用有界重试和保守冷却，未知原因保持未知。
- 这是独立试用版本。隔离宿主与合成模型验证不等于真实模型语义或 Android 实机验收；未验证其它酒馆版本与所有第三方扩展组合。
